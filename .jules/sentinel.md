## 2024-05-24 - Prevent Stack Trace Leakage and Ensure Defense-in-Depth for File Uploads
**Vulnerability:** Unhandled exceptions in model prediction on user-uploaded files expose internal stack traces (information disclosure). Additionally, solely relying on UI component disabled states for input validation can lead to unexpected state execution.
**Learning:** File processing and model inferences must be wrapped in `try...except` blocks to catch unexpected errors from potentially malformed user uploads, with errors logged securely. Also, explicit backend checks for missing data (`None`) are required as defense-in-depth regardless of UI control states.
**Prevention:** Wrap model prediction logic in `try...except`, use generic error messages for the user, log full exception details internally using `logging.error`, and explicitly check that the file object is not `None` before processing.
