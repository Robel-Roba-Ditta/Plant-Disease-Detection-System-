## 2024-05-24 - Unhandled Exceptions Leaking Stack Traces in Streamlit
**Vulnerability:** Unhandled exceptions during file processing and model prediction in the Streamlit interface can leak internal stack traces to the user, potentially exposing sensitive information like internal file paths, model structures, or dependency versions.
**Learning:** In Streamlit applications, default error handling displays the full Python stack trace to the UI. Even with UI element `disabled` states, explicit `None` checks and `try...except` blocks are necessary as a defense-in-depth measure against unexpected state behaviors or malformed inputs.
**Prevention:** Wrap all file processing and model prediction logic in explicit `try...except` blocks. Log the detailed error internally using `logging.error` and display a generic, user-friendly error message using `st.error` to prevent information disclosure.
